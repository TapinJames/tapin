# Tap in

Students tap their phone on an NFC tag inside the classroom door: attendance is recorded on the teacher's dashboard and the phone goes into class mode — distracting apps blocked until the bell, calls and Messages always working.

This repository holds the whole product: iOS app, Android app, Supabase backend, and the teacher/district web dashboards.
