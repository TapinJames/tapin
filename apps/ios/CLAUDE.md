# apps/ios — rules for Claude Code

Read the root `CLAUDE.md` first. Then `docs/ios.md`.

- Swift 5.10+, SwiftUI, iOS 17.0 deployment target, Xcode project generated by **XcodeGen** from `project.yml` — never edit the `.xcodeproj` by hand; edit `project.yml` and regenerate. The generated `TapIn.xcodeproj` is git-ignored.
- Targets: `TapIn` (app), `TapInMonitor` (DeviceActivityMonitor extension), `TapInTunnel` (packet tunnel extension). Bundle ids and entitlements in `docs/ios.md`. Entitlement files live next to each target and are committed.
- Shared code between app and extensions goes in `Sources/Shared/` (App Group paths, models, the blocklist reader). Extensions must stay small and must not import UI.
- No third-party packages in v1 unless the brief says so. (Supabase Swift client arrives in T-006 by brief.)
- Secrets: none in the app. The Supabase anon key + URL go in `Config.xcconfig` (committed, public values) — the service role key never appears anywhere here.
- Keychain for the device credential; App Group container for policy/blocklist files and the VPN stop marker; UserDefaults only for non-sensitive UI state.
- Logging: `os.Logger` with subsystem `com.tapinschools.tapin`; never log names, tokens, or DNS query names.
- Every task ends with a build for James's device and a step-by-step physical test in the report. The simulator proves nothing for NFC, Screen Time or the VPN.
- UI follows `docs/design/tapin-ios-app_v05.html` once we reach the real screens (T-006+); early tasks use plain screens.
